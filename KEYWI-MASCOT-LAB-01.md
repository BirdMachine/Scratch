## 03 // FUZZY CRT // HER DIAGNOSTIC EQUIPMENT IS QUESTIONABLE 📺

Keywi is polished modern software surrounded by tiny pieces of suspicious laboratory surplus.

CRT elements should remain **small**. They work best as living status organs inside otherwise useful tables:

| instrument | signal | Keywi interpretation |
|---|---|---|
| tiny scope | `typing` | input activity / playback |
| phosphor heartbeat | `build` | CI is alive, probably |
| RGB scope | `theme` | chroma/customization preview |
| noisy scope | `experimental` | feature has discovered opinions |

Visual recipe: curved dark glass, subtle scanlines, fuzzy phosphor, bloom, slight RGB misregistration, and a moving hotspot. **Never clean LCD perfection.**

A transparent mascot cutout crouching beside / leaning over a tiny CRT rack would be excellent documentation art without requiring the whole README to become an illustration.

## 05 // KEYCAP CARTRIDGES

The glowing keycap Keywi is holding is too good to remain merely character art. It can become the geometry for small feature sockets.

```text
╭────────╮  ╭────────╮  ╭────────╮  ╭────────╮
│  SWIPE │  │  BOARD │  │  SOUND │  │  GIF   │
│    ✦   │  │   🥝   │  │   ♪    │  │   ◇    │
╰────────╯  ╰────────╯  ╰────────╯  ╰────────╯
```

Actual SVG treatment: thick transparent acrylic, offset rear edge, restrained internal bloom, one tiny specular sweep, and a semantic edge color. A selected/active keycap can briefly refract RGB at an edge instead of simply glowing harder.

**Potential semantic family:**

- cyan — input / typing
- lime — stable / core
- magenta — creative / rendering
- amber — caution / experimental
- violet — advanced / weird little machine

## 07 // NATIVE TABLE = KEYWI WORKBENCH

We keep the strongest rabbit-chamber discovery:

> **GitHub cell padding is clearance. Borders are chassis seams. Row striping is material depth.**

Do not fight the grid. Give each row a bounded organ.

| socket | subsystem | state | native information |
|---|---|---|---|
| 🩵 | gesture engine | LIVE | swipe actions and board paging |
| 💚 | board system | STABLE | alpha / number / emoji / custom boards |
| 💗 | overlay renderer | EXPERIMENTAL | GIF / PNG action reactions |
| 💛 | sound engine | TUNABLE | per-key / per-type / sequence / random |
| 💜 | advanced tools | WEIRD | Unicode, kaomoji, transforms, utilities |

Eventually replace the emoji sockets with our tiny SVG organs: micrometers, fuzzy CRTs, glass cartridges, or refracted tabs. The text remains native, selectable, accessible Markdown.

## 08 // ANIMATION GRAMMAR

The Keywi repo should not become a slot machine. Every animated family gets a different temporal personality:

- **CRT:** quick continuous crawl; environmental electrical life.
- **glass optics:** discrete causal event; something enters, transforms, exits.
- **meters:** slow drift or meaningful state change.
- **specular glass sweep:** rare and slow.
- **pixel heart / mascot accent:** occasional pulse, not perpetual screaming.
- **RGB refraction:** triggered visual punctuation; rainbow is the signal.

Where practical, every reusable animated primitive gets a reduced-motion/static sibling.

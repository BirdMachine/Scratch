The bottom taskbar is painted independently into all three files, so the separate DOM objects pretend to be one continuous screen. This is the useful trick: **a sufficiently coordinated set of images can hide Markdown's layout boundaries.**

The destinations are also `.md` pages now. We have crossed from fancy documentation into a **README labyrinth**.

## 17 — Markdown As Architecture

<a href="./ROOM-BIRD.md">🦜 BIRD ROOM</a> · <a href="./ROOM-VOID.md">🕳️ BASEMENT</a> · <a href="./README.md">🌈 ORIGINAL REALITY</a>

Separate Markdown files can act like rooms/screens/routes. They retain GitHub navigation around the edges, but inside the content area we can maintain an entirely fake visual metaphor. A repo can therefore behave like a tiny static hypertext adventure without GitHub Pages.

## 18 — Intentional Vertical Space As A Material

GitHub is aggressively document-shaped, which means **distance itself** can become part of the gag. `ROOM-VOID.md` uses boring `<br>` tags to turn scrolling into movement through a physical-feeling empty basement. Primitive? Yes. Effective? Also yes.

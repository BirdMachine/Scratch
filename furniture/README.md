# 🪑 ILLEGAL GITHUB FURNITURE WAREHOUSE

This directory is a parts bin, not a theme.

The experiment: make README layout feel like **objects arranged around native Markdown** rather than a poster pasted behind it. GitHub keeps doing the boring, useful job of rendering text; these SVG pieces merely insist that the text is sitting inside a strange physical machine.

## specimen families

| family | object | material hallucination | useful for |
|---|---|---|---|
| `01-optical-bench` | scientific rail / instrument header | anodized aluminum + glass optics | technical docs, Brill, hardware |
| `02-keywi-control-bank` | keyboard/control surface | translucent keycaps + phosphor | Keywi, tools, controls |
| `03-aquarium-window` | impossible viewport | acrylic + caustic water + chrome | PaidIn / Ocean Dolphin Aero |
| `04-resin-specimen` | cast specimen label | pink resin + embedded junk | Feist, collections, playful docs |
| `05-crt-rack` | rackmount terminal bay | smoked glass + old phosphor CRT | build/status/dev sections |
| `06-prismatic-spine` | asymmetric page spine | dichroic glass + edge light | navigation, long READMEs |
| `07-ceramic-service-panel` | appliance/service hatch | glossy ceramic + warning labels | install/config/troubleshooting |
| `08-bubble-console` | soft pneumatic controls | clear inflatable polymer | whimsical UI/projects |

## design law

**Do not draw the page. Draw evidence that a device exists around the page.**

That means discontinuous rails, tabs that disappear behind Markdown, holes with no obvious purpose, optical elements whose beam continues in your imagination, status lamps, material seams, and pieces that only make sense when separated by ordinary GitHub content.

The negative space is a component too. ♡
